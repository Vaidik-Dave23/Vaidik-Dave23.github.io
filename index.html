01 Flagship

Auvon.ai

AI study workspace with a fault-tolerant RAG backend

  • Engineered a 3-tier cascading LLM failover layer (Gemini + OpenAI fallback) across up to 19 rotating keys with exponential backoff, cutting provider quota-exhaustion downtime to near zero.
  • Raised RAG faithfulness from 14% to 81% through semantic chunking and evaluation-driven retrieval redesign, measured with a self-built LLM-as-judge harness (81% faithfulness, 99% relevance).
  • Instrumented the full request lifecycle with structured JSON logging, Prometheus metrics, and OpenTelemetry tracing, visualized in a self-hosted Grafana + Jaeger dashboard.
  • Deployed containerized microservices on Google Cloud Run for horizontally scalable inference.

DocMind

Multi-document RAG benchmarking & evaluation engine

  • Benchmarked 4 chunking strategies against a dense 502-page legal corpus — naive fixed-size chunking outperformed semantic and hierarchical chunking on retrieval precision, a documented counter-intuitive result.
  • Built a custom RAGAS-style faithfulness evaluator with embedding-based caching, cutting LLM API calls per query from 8 to 2 (75% reduction).

Recoup

AI-powered payment recovery platform with a confidence-gated LangGraph agent

  • Built a stateful LangGraph recovery agent (triage → strategize → generate content → execute, or escalate) powered by Gemini, with a confidence threshold and max-attempt limit enforced in backend logic rather than left to the prompt.
  • Wired the agent's output to real recovery actions: Razorpay test-mode Payment Links and optional SMTP outreach, with every action, escalation, and outcome persisted for audit and traceability.
  • Shipped a full-stack system solo — FastAPI + async SQLAlchemy/PostgreSQL backend on Azure App Service, React/TypeScript merchant dashboard on Vercel, with JWT auth and merchant-scoped data isolation.
  • Fixed a production auth bug by pre-hashing passwords with SHA-256 before bcrypt, removing bcrypt's 72-byte truncation limit while staying backward-compatible with legacy hashes.
