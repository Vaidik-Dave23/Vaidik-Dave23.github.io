  • One provider-agnostic model router behind every call: Gemini 3.5 Flash, then Gemini 2.5 Flash, then OpenAI gpt-4o-mini. Latency-sensitive paths like streaming and live voice start on 2.5 Flash with thinking off. If every provider fails, it returns a 502 with the last error instead of hanging.
  • Quota-aware error handling: 429s are classified from the QuotaFailure quotaId, so a per-minute limit moves on immediately and only real per-day exhaustion is parked until UTC midnight. This fixed a false-blacklisting bug that was taking usable capacity offline. Timeouts are never retried on the same slow path.
  • Streaming over SSE for notes, document Q&A and the tutor. Failover switches provider only before the first token, so text on screen is never restarted. First text in 1.0 s instead of 29.5 s.
  • Grounded RAG: a structure-aware chunker (headings, then paragraphs, then sentences, each chunk prefixed with its heading), gemini-embedding-001, in-memory cosine ranking in 30 ms, a [Source N] citation on every claim and a fixed refusal line. 11 of 12 unanswerable questions refused.
  • Voice tutor that teaches in parts with a whiteboard, prefetching the next part while the current one plays, and re-explains a doubt a different way each time. Speech runs in the browser, so voice adds no API cost.
  • Production hygiene: rotating refresh tokens with token_version revocation, email verification, SlowAPI rate limits, ownership checks, Prometheus and OpenTelemetry. 78 tests gate an OIDC deploy to Azure App Service, and trimming dependencies took the install from 732 MB to 150 MB.

  • Benchmarked 4 chunking strategies on a dense 502-page legal judgment. Naive fixed-size chunking beat semantic and hierarchical chunking on context precision, a documented counter-intuitive result.
  • Built a RAGAS-style evaluator that cut LLM calls per query from 8 to 2 with batched judge prompts, local Sentence-Transformers similarity for relevancy, and SHA-256 score caching.
  • Cached chunk embeddings once at upload so compare mode stops re-running encode() on every request, which fixed a major latency issue.
  • Added a retrieval-only /debug/retrieve endpoint and an R@k / MRR benchmark to test retrieval separately from generation.
  • Fixed a silent retrieval failure from a metadata schema mismatch, and a module-scoping bug where direct imports held stale copies of the live FAISS store. Soft-delete on FAISS IndexFlatL2 trades memory for compute.
